# 分享说明（可直接转发）

## 给朋友的话

这是我做的一个**行测模考记录工具**，免费、不用注册，数据只存在你自己的手机/电脑里，不会上传。

### 方式一：网页版（最快，推荐先试）

1. 用手机浏览器打开：**https://kingofluxury.github.io/1256/**
2. 点浏览器菜单 → **添加到主屏幕**，之后就像 App 一样用
3. 每次模考后：填「第几次、卷名（可选）、日期」，再填 12 个题型的**答对数**和**用时（分钟）**
4. 点保存，去「曲线」看每个题型的正确率和用时

注意：
- 不要用无痕模式
- 清理浏览器数据会清空记录，建议每周「设置 → 导出备份」
- iPhone 也能用网页版，添加到主屏幕即可

### 方式二：安卓 App

1. 我直接把 `app-debug.apk` 发给你（不用自己去下载）
2. 手机上点开安装，提示「未知来源」时选择允许；这是个人应用，没有上架商店
3. 打开就能用，操作和网页版一样

注意：
- 卸载 App 会清空里面的数据，卸载前一定先导出备份
- 更新时直接安装新包覆盖即可，数据保留
- 只支持安卓；iPhone 用网页版

### 数据备份（两种方式都适用）

- 导出：设置 → 导出 JSON 备份（网页版会下载文件，App 里可能复制到剪贴板）
- 导入：设置 → 导入 JSON 备份，重复的「第几次」会自动跳过
- 换手机、清缓存、卸载前，先导出

### 两个常见问题

- **网页版和 App 的数据互通吗？** 不互通。它们是两套本地存储，选一个长期用。
- **别人能看到我的成绩吗？** 看不到。数据只在你的设备里，服务器只负责发网页文件。

1. **网址**：https://kingofluxury.github.io/1256/

3. **提醒对方**：先导出备份再清缓存/卸载；网页版和 App 数据不互通。
