# 行测模考分析器 · 微信小程序版

这是独立的小程序工程，和仓库里的桌面版 / 网页版**互不影响**。
纯计算逻辑（题型结构、得分、期望分、标准误）从 `app/public/shared/` 生成，UI 用小程序原生重写。

## 打开方式

1. 安装「微信开发者工具」
2. 导入项目，目录选择本文件夹 `miniprogram/`
3. AppID 可以先用「测试号 / 游客模式」，发布前换成自己的小程序 AppID
4. 编译即可运行

## 目录

```
miniprogram/
  app.js / app.json / app.wxss
  project.config.json      小程序工程配置（appid 为占位）
  utils/
    core.js                由 shared/*.js 打包生成（勿手改）
    version.js             构建版本号（勿手改）
    store.js               本地存储与增删改查
    fmt.js / chart.js      格式化与 Canvas 绘图
  pages/
    index/                 录入
    records/               记录
    curves/                曲线
    settings/              结构、导入导出、关于
```

## 重新生成 core.js / version.js

修改 `app/public/shared/` 或版本号后，在仓库根目录执行：

```bash
npm run build:mp
```

## 功能

- 选择「考试类型 + 试卷类型」，按 4 套结构录入
- 每种试卷独立编号
- 卷名、备注、日期
- 记录列表、按试卷筛选、编辑、删除、移动顺序
- 正确率曲线（整卷 + 各模块，Canvas 绘制）
- 导出/导入 JSON（通过剪贴板）
- 数据只存在本机，不上传

## 与桌面版的差异

| 项 | 小程序版 | 桌面版 |
|---|---|---|
| 图表 | Canvas 手绘（正确率） | ECharts（正确率 + 用时 + 数值标注） |
| 备份 | 复制 JSON 到剪贴板 | 直接写入 `data/backups/` |
| 数据 | 微信本地存储，与桌面/网页不互通 | SQLite / IndexedDB |

## 发布前需要准备（平台层面）

1. **小程序账号**：邮箱注册，个人或企业主体，拿到 AppID
2. **服务类目**：考试工具容易被归到「教育」，可能需要资质；个人主体建议先试「工具」类目
3. **ICP 备案**：2023 年起小程序必须备案，在微信公众平台提交主体与服务信息
4. **个人主体限制**：不能用 `web-view`，所以不能直接套网页版，必须像本工程这样原生实现
5. **隐私**：即使不采集数据，也要在「用户隐私保护指引」里说明本地存储
6. **审核材料**：功能说明、截图、测试路径、免责声明（不提供题库、不涉及作弊）

## 已知限制

- 不包含题库，只处理用户录入的统计数字
- 小程序包体积限制：本工程未引入 ECharts，主包很小
- 国考副省级按原始口径为 100.5 分
